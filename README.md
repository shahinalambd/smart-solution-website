# Smart Solution Pest Control Website

A clean, trustworthy website concept for a pest control company in Muscat, Oman, available in English and Arabic.

## Live preview

https://shahinalambd.github.io/smart-solution-website/

## Key features

- 5 pages with a shared header, footer and map rendered from one config
- English / Arabic toggle with RTL layout
- Interactive treatment planner that suggests a plan by property type, size and pests
- Project gallery with lightbox
- Inspection booking form with client-side validation
- Fully responsive layout

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
